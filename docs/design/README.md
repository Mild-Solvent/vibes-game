# friendslop

A co-op "friendslop" game about **being the crew behind a live show**. The show goes
out whether you're ready or not. The audience only sees what's on stage or on camera,
and everything behind it is chaos.

Working title: **STANDBY... GO!** (see [naming](01-concept/pitch.md#working-titles))

Launch modes:
- **We're Live!**: crew of a live TV news broadcast
- **Places, Please!**: backstage crew of a live theatre play

Status: **grey-box prototype in Godot 4** (see the repo root README).
